# 此电脑/桌面 流氓图标清理工具 (IconCleaner)

一键扫描并清理 Windows「此电脑」页面与桌面上的第三方/流氓命名空间图标，
例如「百度网盘：双击运行百度网盘」、阿里云盘、夸克网盘、迅雷、360、2345 等。

**零依赖**：仅使用 Windows 自带的 PowerShell 5.1，无需安装任何软件。

## 快速开始

1. 双击 `启动图标清理工具.bat`（自动申请管理员权限）；
2. 程序自动扫描并弹出界面，红色加粗的「疑似流氓」项已默认勾选；
3. 按需增删勾选（**删除哪一个完全由你决定**），点击「删除选中项」；
4. 确认后程序自动备份，并询问是否重启资源管理器使图标立即消失。

## 功能清单

| 功能 | 说明 |
| --- | --- |
| 自动扫描 | 覆盖 12 个注册表位置（此电脑/桌面 × HKCU/HKLM × 64/32 位 × 普通/DelegateFolders） |
| 自动分类 | 系统默认 / 微软 / 第三方 / 疑似流氓 / 已免疫 / 未知 |
| 自定义删除 | 列表中逐项勾选，想删哪个删哪个；支持搜索筛选 |
| 删除前备份 | 完整保存键值类型与数据（JSON），可一键恢复 |
| 免疫防复活 | 删除后写入拒绝权限，防止软件下次启动重新创建图标 |
| 注册表定位 | 双击某行或右键菜单直接跳转到对应注册表键 |
| 报告与日志 | 导出 CSV 扫描报告；操作日志保存在 `data/log.txt` |
| 命令行模式 | `-ScanOnly` 仅扫描输出；`-SelfTest` 自检备份/删除/恢复/免疫逻辑 |

## 原理

「此电脑」和桌面上的第三方图标本质是软件注册的 **Shell 命名空间扩展（CLSID）**，
挂载在以下注册表位置（删除对应子键即可移除图标，不影响软件本身的安装）：

| 注册表位置 | 作用 |
| --- | --- |
| `HKLM\SOFTWARE\...\Explorer\MyComputer\NameSpace` | 此电脑图标（64 位软件） |
| `HKLM\SOFTWARE\WOW6432Node\...\MyComputer\NameSpace` | 此电脑图标（32 位软件） |
| `HKCU\Software\...\MyComputer\NameSpace` | 此电脑图标（当前用户） |
| `HKLM / HKCU ...\Explorer\Desktop\NameSpace` | 桌面图标（如「双击运行百度网盘」） |
| 各处的 `DelegateFolders` | 委托文件夹类图标 |

## 自定义

- **signatures.json**（工具同目录）：流氓关键词、第三方关键词、系统白名单 CLSID，可直接编辑；
- **config.json**（`data` 目录）：记忆界面选项；
- 界面上的「显示系统项」可查看并管理 Windows 自带图标项（慎删）。

## 注意事项

- 需要管理员权限（批处理会自动申请 UAC）；
- 本工具只删除注册表中的**图标挂载项**，不卸载软件；软件更新/重装后可能重新创建图标，勾选「免疫防复活」可防止；
- 误删可用「恢复备份」还原（备份位于 `data\backups\`）；
- 「免疫」键显示为绿色斜体，删除免疫键即解除免疫；
- 重启资源管理器会关闭所有已打开的资源管理器窗口。

## 常见问题

**Q: 删除后图标还在？**
A: 点击「重启资源管理器」立即生效；若软件正在运行并重新注册图标，请勾选「免疫防复活」后再删。

**Q: 恢复备份后图标没有出现？**
A: 重启资源管理器即可。

**Q: 提示无法删除？**
A: 工具会自动修复注册表权限后重试；若仍失败，请以管理员身份运行，或进入安全模式删除。
